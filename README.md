# Movie Data Analysis — Apache Pig

The project uses **Pig Latin** scripts to extract insights about movie popularity, ratings, user activity, tags, and genre preferences.



## Project Overview

The project is divided into three main analyses:

* **General Movie Analysis** — analysis of ratings, movie popularity, user activity, and tags.
* **Specific Movie Analysis** — detailed information and rating statistics for a selected movie.
* **User & Genre Analysis** — identification of user genre preferences and overall genre trends.



## Technologies

* Apache Pig
* Pig Latin
* Hadoop
* CSV datasets



## Main Pig Operations

The project makes use of several Apache Pig operations, including:

`LOAD` · `FILTER` · `FOREACH` · `GROUP` · `JOIN` · `ORDER` · `COUNT` · `AVG` · `MIN` · `MAX` · `TOKENIZE` · `FLATTEN` · `TOP` · `STORE`



## Project Focus

This project demonstrates the use of **Apache Pig for Big Data analysis**, covering data cleaning, transformation, joining, grouping, aggregation, and extraction of meaningful insights from multiple datasets.
